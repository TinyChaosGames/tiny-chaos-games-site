# Tiny Chaos Games — GitHub Pages

Static website and ONE MORE PIXEL Privacy Policy.

## Deploy
1. Create a **public** GitHub repository named `tiny-chaos-games-site`.
2. Upload `index.html`, `style.css`, `.nojekyll`, and the `privacy/one-more-pixel/index.html` folder structure to the repository root.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Website: `https://YOUR-USERNAME.github.io/tiny-chaos-games-site/`
5. Privacy policy: `https://YOUR-USERNAME.github.io/tiny-chaos-games-site/privacy/one-more-pixel/`

**Before publishing:** Review the policy against the final APK, the Android backup configuration, target-age and Families declarations, AdMob/UMP configuration, actual collection by Google SDKs, data safety declaration, and the exact contact information. This is an editable draft, not legal advice.
